
# Chrono Vehicle – Tracked Vehicle / Sprocket

## 1. Sprocket이란?

`Sprocket`은 tracked vehicle에서 **구동륜**에 해당하는 부품이다. 일반적인 바퀴처럼 지면과 직접 접촉해서 차량을 움직이는 것이 아니라, **드라이브라인(driveline) 또는 파워트레인에서 전달된 회전 운동/토크를 트랙 슈(track shoe) 또는 연속 트랙에 전달**하는 역할을 한다.

Chrono 문서에서는 sprocket subsystem이 다음 두 영역을 연결한다고 설명한다.

- tracked vehicle의 **driveline**
- **track assembly**

또한 sprocket은 track shoe body와의 **collision detection** 및 **contact processing**을 담당한다. 즉, sprocket은 단순히 회전하는 시각적 모델이 아니라, 트랙 슈와 실제로 맞물리는 접촉 알고리즘을 가진 물리 서브시스템이다.

---

## 2. Chrono에서 Sprocket의 역할

Chrono::Vehicle에서 sprocket은 다음 기능을 수행한다.

### 2.1 드라이브라인과 트랙의 연결

차량의 엔진, 변속기, 드라이브라인에서 나온 구동 토크는 sprocket의 axle/shaft로 전달된다. 이후 sprocket이 회전하면서 track shoe와 접촉하고, 이 접촉력에 의해 트랙이 움직인다.

즉, tracked vehicle의 구동 흐름을 단순화하면 다음과 같다.

```
Engine / Transmission        
↓
Driveline        
↓
Sprocket axle        
↓
Sprocket gear body        
↓
Track shoe contact        
↓
Track motion        
↓
Vehicle motion
```

Chrono의 `ChSprocket` 계열 클래스는 sprocket gear body, axle shaft, revolute joint, contact material 등을 내부적으로 가진다. 공식 API에는 `GetGearBody()`, `GetAxle()`, `GetRevolute()`, `GetAxleSpeed()`, `ApplyAxleTorque()` 같은 함수가 제공된다.

---

### 2.2 Track shoe와의 접촉 처리

Chrono의 sprocket은 일반적인 mesh collision만으로 트랙과 맞물리는 것이 아니라, **custom collision callback**을 사용한다. 문서에 따르면 sprocket subsystem template은 sprocket gear profile과 대응되는 track shoe 사이의 일관된 접촉 처리를 위해 custom collision detection algorithm을 구현한다.

중요한 점은 다음과 같다.

- sprocket gear profile은 2D path로 정의된다.
- 이 2D path는 line segment와 circular arc로 구성된다.
- collision detection은 sprocket gear plane에서 2D로 수행된다.
- 하지만 contact force는 3D에서 계산되어 sprocket과 track shoe body에 적용된다.

즉, 기하학적 맞물림 판단은 2D에서 단순화해서 처리하지만, 실제 힘과 운동은 3D rigid body simulation 안에서 적용된다.

---

## 3. Sprocket의 주요 하위 분류

Chrono 문서의 `Sprocket models` 페이지에서는 sprocket을 track shoe의 종류에 따라 크게 세 가지로 나눈다.

```
Sprocket
├── Single-pin sprocket
├── Double-pin sprocket
└── Band-track sprocket
```

공식 문서 설명 중 “two templates”라고 되어 있지만, 바로 뒤에서 single-pin, double-pin, band track 세 종류를 나열하고 있다. 실제 API에도 세 계열이 존재하므로, 문서 작성 시에는 **세 종류의 sprocket template이 제공된다**고 정리하는 것이 실용적으로 맞다.

---

## 4. Single-pin Sprocket

### 4.1 개념

`Single-pin sprocket`은 **single-pin track shoe**와 맞물리도록 설계된 sprocket이다. 기어 프로파일은 circular arc들로 구성된다.

Chrono의 기본 클래스는 다음과 같다.

```
chrono::vehicle::ChSprocketSinglePin
```

이 클래스는 circular arc로 구성된 sprocket gear profile을 가지는 sprocket template의 base class이다. 공식 문서에서도 single-pin track shoe와의 상호작용에 적합하다고 설명한다.

---

### 4.2 주요 기능

`ChSprocketSinglePin`에서 중요한 기능은 다음과 같다.

|기능|설명|
|---|---|
|`GetProfile()`|sprocket의 2D gear profile을 반환|
|`GetCollisionCallback(track)`|track assembly와의 custom collision callback 반환|
|`GetTemplateName()`|subsystem template 이름 반환|

`GetProfile()`은 `ChLinePath` 형태의 2D gear profile을 반환한다. 이 profile은 `ChLineArc` 또는 `ChLineSegment` 타입의 sub-path로 구성될 수 있으며, sub-path들은 시계방향으로 추가되어야 하고, 각 sub-path의 끝점은 다음 sub-path의 시작점과 일치해야 한다.

---

### 4.3 M113 Single-pin Sprocket

M113 모델에는 다음 클래스가 제공된다.

```
chrono::vehicle::m113::M113_SprocketSinglePin
chrono::vehicle::m113::M113_SprocketSinglePinLeft
chrono::vehicle::m113::M113_SprocketSinglePinRight
```

`M113_SprocketSinglePin`은 M113 차량용 single-pin track shoe와 맞물리는 sprocket base class이다.

M113 single-pin sprocket의 주요 파라미터는 다음과 같다.

|항목|값|
|---|---|
|Number of teeth|10|
|Gear mass|27.68 kg|
|Axle inertia|0.4 kg·m²|
|Gear profile separation|0.225 m|
|Lateral backlash|0.02 m|

이 값들은 `M113_SprocketSinglePin`의 static protected attributes로 정의되어 있다.

---

## 5. Double-pin Sprocket

### 5.1 개념

`Double-pin sprocket`은 **double-pin track shoe**와 맞물리도록 설계된 sprocket이다. 이 sprocket의 gear profile은 circular arc와 flat seat로 구성된다.

기본 클래스는 다음과 같다.

```
chrono::vehicle::ChSprocketDoublePin
```

---

### 5.2 주요 기능

Double-pin sprocket도 single-pin과 유사하게 다음 기능을 제공한다.

|기능|설명|
|---|---|
|`GetProfile()`|2D gear profile 반환|
|`GetCollisionCallback(track)`|track assembly와 맞물림을 처리하는 custom collision callback 반환|
|`GetTemplateName()`|subsystem template 이름 반환|

Double-pin sprocket은 single-pin과 달리 profile이 circular arc만이 아니라 **flat seat**를 포함한다. 이는 double-pin track shoe의 형상과 접촉 구조가 single-pin보다 복잡하기 때문이다.

---

### 5.3 M113 Double-pin Sprocket

M113 모델에는 다음 클래스가 제공된다.

```
chrono::vehicle::m113::M113_SprocketDoublePin
chrono::vehicle::m113::M113_SprocketDoublePinLeft
chrono::vehicle::m113::M113_SprocketDoublePinRight
```

`M113_SprocketDoublePin`은 M113 차량용 double-pin track shoe와 맞물리는 sprocket base class이다.

M113 double-pin sprocket의 주요 파라미터는 다음과 같다.

|항목|값|
|---|---|
|Number of teeth|10|
|Gear mass|27.68 kg|
|Axle inertia|0.4 kg·m²|
|Gear profile separation|0.278 m|
|Lateral backlash|0.02 m|

이 값들은 `M113_SprocketDoublePin`의 static protected attributes로 정의되어 있다.

---

## 6. Band-track Sprocket

### 6.1 개념

`Band-track sprocket`은 segmented track shoe가 아니라 **continuous-band track**과 상호작용하도록 설계된 sprocket이다. 문서에 따르면 band-track sprocket의 gear profile도 circular arc와 flat seat로 구성된다.

기본 클래스는 다음과 같다.

```
chrono::vehicle::ChSprocketBand
```

---

### 6.2 M113 Band Sprocket

M113 모델에는 다음 클래스가 제공된다.

```
chrono::vehicle::m113::M113_SprocketBand
chrono::vehicle::m113::M113_SprocketBandLeft
chrono::vehicle::m113::M113_SprocketBandRight
```

M113 band sprocket은 M113의 continuous band track 모델과 함께 사용된다. M113 모델 전체에서는 segmented single-pin, segmented double-pin, band-bushing, band-ANCF 계열의 차량 구성이 제공된다.

M113 band sprocket의 주요 파라미터는 다음과 같다.

|항목|값|
|---|---|
|Number of teeth|17|
|Gear mass|27.68 kg|
|Axle inertia|0.4 kg·m²|
|Gear profile separation|0.278 m|
|Lateral backlash|0.02 m|

이 값들은 `M113_SprocketBand`의 static protected attributes로 정의되어 있다.

## 7. 공통적으로 중요한 함수와 의미

### 7.1 `GetNumTeeth()`

```
virtual unsigned int GetNumTeeth() const = 0;
```

sprocket gear의 tooth 개수를 반환한다. M113 single-pin과 double-pin은 10개, band sprocket은 17개로 정의되어 있다.

---

### 7.2 `GetAssemblyRadius()`

```
virtual double GetAssemblyRadius() const = 0;
```

track assembly를 자동으로 구성할 때 사용되는 sprocket radius를 반환한다. M113 문서에서는 이 값이 **automatic track assembly**에 사용된다고 설명한다.

---

### 7.3 `GetAddendumRadius()`

```
virtual double GetAddendumRadius() const = 0;
```

sprocket-track engagement에 사용되는 평균 반경이다. M113 문서에서는 이 값이 **longitudinal slip**을 추정하는 데 사용된다고 설명한다.

쉽게 말하면, sprocket이 회전할 때 이론적으로 트랙을 얼마나 전진시키는지 계산할 때 중요한 유효 반경이다.

---

### 7.4 `GetGearBody()`

```
std::shared_ptr<ChBody> GetGearBody() const;
```

sprocket gear body에 접근하는 함수이다. 이 body는 Chrono 물리 시스템 안에서 실제 질량과 관성을 가진 rigid body로 취급된다.

---

### 7.5 `GetAxle()`

```
std::shared_ptr<ChShaft> GetAxle() const;
```

sprocket의 axle shaft에 접근하는 함수이다. driveline에서 전달된 회전 운동/토크는 이 shaft를 통해 sprocket에 전달된다.

---

### 7.6 `GetAxleSpeed()`

```
double GetAxleSpeed() const;
```

sprocket axle의 angular speed를 반환한다. 시뮬레이션 중 sprocket 회전 속도를 확인하거나 slip, track speed 등을 계산할 때 유용하다.

---

### 7.7 `ApplyAxleTorque(double torque)`

```
void ApplyAxleTorque(double torque);
```

sprocket axle에 직접 torque를 적용하는 함수이다. 공식 문서에서는 debugging과 testing을 위한 함수라고 설명한다. 실제 차량 모델에서는 보통 driveline/powertrain이 torque를 전달하지만, 특정 조건에서 sprocket만 따로 테스트할 때 사용할 수 있다.

---

### 7.8 `EnableCollision(bool val)`

```
void EnableCollision(bool val);
```

sprocket gear wheel의 collision flag를 켜거나 끄는 함수이다.

주의할 점은, sprocket-track 상호작용에서는 일반 collision뿐 아니라 custom collision callback이 중요하므로, 단순히 mesh collision만 생각하면 안 된다.

---

### 7.9 `DisableLateralContact()`

```
void DisableLateralContact();
```

기본적으로 Chrono의 sprocket은 detracking, 즉 트랙이 옆으로 빠지는 현상을 방지하기 위한 lateral contact를 활성화한다. `DisableLateralContact()`는 이 lateral contact를 비활성화한다.

문서화할 때는 다음처럼 설명하면 좋다.

> Lateral contact는 트랙 슈가 sprocket에서 옆 방향으로 이탈하는 것을 방지하기 위한 보조 접촉 모델이다. 현실적인 detracking까지 완전히 재현하려는 경우와 안정적인 주행 시뮬레이션을 원하는 경우에 설정 의도가 달라질 수 있다.

---

## 8. M113 모델에서 Sprocket의 위치

Chrono의 M113 모델은 tracked vehicle 예제 중 하나이며, M113 tracked vehicle 모듈에는 chassis, driveline, idler, suspension, road wheel, sprocket, track assembly, track shoe 등이 포함된다.

M113에서 sprocket은 다음 track assembly 구성과 맞물린다.

```
M113_Vehicle_SinglePin 
└── M113_TrackAssemblySinglePin      
	├── M113_SprocketSinglePinLeft / Right      
	└── M113_TrackShoeSinglePin
M113_Vehicle_DoublePin 
└── M113_TrackAssemblyDoublePin      
	├── M113_SprocketDoublePinLeft / Right      
	└── M113_TrackShoeDoublePin
M113_Vehicle_BandBushing or BandANCF 
└── M113_TrackAssemblyBand...      
	├── M113_SprocketBandLeft / Right      
	└── M113_TrackShoeBand...
```

M113 모델 페이지에는 `M113_Vehicle_SinglePin`, `M113_Vehicle_DoublePin`, `M113_Vehicle_BandBushing`, `M113_Vehicle_BandANCF`가 제공된다고 정리되어 있다. 또한 각각에 대응되는 track assembly와 track shoe 클래스도 제공된다.

## 9. 사용 시 주의할 점

### 9.1 Sprocket과 track shoe 타입은 반드시 맞아야 한다

Single-pin sprocket은 single-pin track shoe와, double-pin sprocket은 double-pin track shoe와, band sprocket은 continuous-band track과 맞도록 설계되어 있다. 각 sprocket template은 대응되는 sprocket gear profile과 track shoe 조합에 대해 custom collision detection algorithm을 구현한다.

따라서 다음처럼 섞어서 쓰면 안 된다.

```
잘못된 조합 예시:
M113_SprocketSinglePin + M113_TrackShoeDoublePin
M113_SprocketDoublePin + M113_TrackShoeBand
```

이론적으로 컴파일이 되더라도 접촉 형상과 callback이 맞지 않아 비정상적인 결과가 나올 가능성이 높다.

---

### 9.2 Sprocket profile은 시각화 mesh와 다르다

sprocket의 실제 접촉 계산에 쓰이는 것은 단순한 3D mesh가 아니라, 2D gear profile이다. 이 profile은 `ChLinePath`로 정의되고, `ChLineArc`와 `ChLineSegment`로 구성된다.

따라서 CAD mesh를 바꿨다고 해서 sprocket-track 접촉이 자동으로 바뀌는 것은 아니다. 접촉 특성을 바꾸려면 sprocket profile 관련 파라미터를 수정해야 한다.

---

### 9.3 M113 기반 수정 시 봐야 할 항목

M113 sprocket을 수정하거나 응용하려면 다음 항목을 우선 확인하는 것이 좋다.

|확인 항목|이유|
|---|---|
|`GetNumTeeth()`|트랙 피치와 sprocket 맞물림 주기에 직접 영향|
|`GetAssemblyRadius()`|자동 track assembly 배치에 영향|
|`GetAddendumRadius()`|sprocket-track engagement 및 slip 추정에 영향|
|`GetGearMass()`|sprocket 질량|
|`GetGearInertia()`|회전 동역학에 영향|
|`GetAxleInertia()`|driveline-sprocket 회전 응답에 영향|
|`GetSeparation()`|좌우 또는 이중 gear profile 간 거리|
|`GetLateralBacklash()`|lateral contact 허용 유격|
|`CreateContactMaterial()`|접촉 재질 설정|
|`GetMeshFile()`|시각화 mesh 파일|

---

## 10. 한 줄 요약

Chrono Vehicle에서 `Sprocket`은 tracked vehicle의 **구동 토크를 트랙에 전달하는 구동륜 서브시스템**이며, 단순 회전체가 아니라 **track shoe와의 맞물림을 위한 2D gear profile, custom collision callback, 3D contact force 계산, axle/shaft 연결, lateral contact 처리**를 포함하는 핵심 구성요소이다.

M113 모델에서는 track 종류에 따라 다음 sprocket을 사용한다.

```
Single-pin track  → M113_SprocketSinglePin
Double-pin track  → M113_SprocketDoublePin
Band track        → M113_SprocketBand
```

프로젝트에서 M113을 기반으로 응용할 계획이라면, sprocket을 수정할 때는 단순히 3D 형상만 볼 것이 아니라 **track shoe 타입, gear profile, tooth 수, assembly radius, addendum radius, contact material, lateral backlash**를 함께 확인해야 한다.
