Chrono에서 무한궤도 차량은 `ChTrackedVehicle` 클래스를 통해 구현되며, 크게 다음과 같은 계층 구조를 가집니다.

- **Chassis (차체):** 차량의 메인 몸체입니다.
    
- **Driveline (동력 전달 장치):** 엔진의 힘을 스프로킷(Sprocket)으로 전달합니다.
    
- **Track Assembly (궤도 조립체):** 양쪽에 위치하며, 실제 지면과 맞닿아 구동력을 발생시키는 핵심 유닛입니다.

![[Pasted image 20260512020232.png]]
**미국/독일의 시제전차 MBT-70(Kpz-70) 의 Track 설명도**
Suspension: 차량에 가해지는 충격을 흡수하는 차량의 서스펜션과 동일, 각각의 roadwheel(보기륜)과 연결
Sprocket: 엔진의 동력을 이용해 궤도를 회전시키는 역할로, 위 전차의 경우 후방 상단에 위치
Idler: 궤도의 장력을 조절하며 험지 주파를 위해 지면과 유격되어 전차 전방에 위치
Track Shoe: 무한궤도를 이루는 궤도의 체인 각각을 의미

**[[1. Track Assembly]]**: 스프로킷, 아이들러, 전륜, 궤도 마디를 포함하는 전체 컨테이너입니다.

**[[2. Suspension Models]]**: 보기륜(Road-wheel)과 차체를 연결하여 충격을 흡수하는 현가장치 모델입니다.

**[[3. Sprocket Models]]**: 엔진의 회전력을 궤도에 전달하는 '구동륜'에 대한 설명입니다.

**[[4. Idler Models]]**: 궤도의 장력을 조절하고 경로를 가이드하는 '유도륜' 모델입니다.

**[[5. Track Shoe Models]]**: 궤도를 구성하는 개별 마디(신발)의 형상과 연결 방식에 대한 설명입니다.
