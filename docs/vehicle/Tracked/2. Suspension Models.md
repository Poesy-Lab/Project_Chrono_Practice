Chrono의 `Tracked Suspension` 시스템은 크게 현가 메커니즘(Suspension)과 **보기륜(Road-wheel)** 두 가지 부분으로 나뉩니다.

또한 suspension의 경우 물리 및 수학적 규칙을 정의하는 추상 베이스 클래스인 Ch-와 바로 사용 가능한 JSON을 지원하는 템플릿 기반 클래스를 지원합니다.
*새로운 물리법칙이 적용되는 모델을 만드는것이 아니라면 템플릿 기반 클래스 사용을 추천합니다. 또한 이 문서는 템플릿 기반 클래스를 사용한다고 가정하고 작성 할 예정입니다*

| **항목**    | **API 클래스**     | **선택 기준**           | **비고**          |
| --------- | --------------- | ------------------- | --------------- |
| **현가 방식** | `Translational` | 단순한 수직 운동, 빠른 시뮬레이션 | 단순 로봇, 트랙터      |
|           | `Rotational`    | 실제 전차의 암(Arm) 운동 묘사 | 토션 바 방식 구현 시 필수 |
| **바퀴 형상** | `Central-pin`   | 궤도 중앙에 핀이 있는 경우     | 현대식 MBT 대부분     |
|           | `Lateral-pin`   | 궤도 양옆에 가이드가 있는 경우   | 특수 궤도, 소형 기기    |

### **1. 현가 메커니즘 (Suspension Models)**

차체와 보기륜을 연결하는 '팔(Arm)'과 '스프링'의 작동 방식을 결정합니다.

#### **① ChTranslationalDamperSuspension (선형 댐퍼 현가장치)**

- **원리:** 보기륜이 차체에 대해 **직선(Linear/Translational)** 방향으로만 움직입니다.
    
- **물리 모델:** 수직 방향의 선형 스프링과 댐퍼로 구성됩니다.
    
- **해설:** 실제 전차보다는 단순한 궤도형 로봇이나 초기 형태의 궤도 차량에서 볼 수 있는 수직 쇼크 업소버 방식입니다.
    
- **장점:** 구현이 가장 쉽고 계산이 빠릅니다.
    

- **불러올 경우**: 
- #include <ChTranslationalDamperSuspension.h> (물리적 특성을 규정함)
- #include <TranslationalDamperSuspension.h> (바로 사용 가능한 JSON 지원)

#### **② ChRotationalDamperSuspension (회전형 댐퍼 현가장치)**

- **원리:** 보기륜이 **암(Arm)** 끝에 달려 있으며, 이 암이 특정 축을 중심으로 회전(Rotational)하며 충격을 흡수합니다.
    
- **물리 모델:** 암의 회전축에 회전 스프링(Torsional Spring)과 회전 댐퍼가 위치합니다.
    
- **해설:** **이것이 바로 '토션 바(Torsion Bar)' 현가장치를 모델링하는 기본 클래스입니다.** 현대 전차의 대부분은 보기륜이 암에 매달려 위아래로 호를 그리며 움직이기 때문에, 실제 전차를 만든다면 이 모델을 사용해야 합니다.
    
- **불러올 경우**
- #include <ChRotationalDamperSuspension.h>
- #include <RotationalDamperSuspension.h>

### **2. 보기륜 모델 (Road-wheel Models)**

궤도 마디(Track Shoe)의 가이드 핀(Guide Pin)이 어디에 위치하느냐에 따라 보기륜의 형상이 달라집니다. 이는 궤도가 주행 중 이탈하지 않도록 잡아주는 핵심 구조입니다.

#### **① ChCentralPinRoadWheel (중앙 핀용 보기륜)**

- **구조:** 궤도 마디의 정중앙에 솟아 있는 가이드 핀을 수용하기 위해, **보기륜이 두 개의 얇은 바퀴로 나뉘어(Double-faced)** 그 사이로 핀이 지나가는 구조입니다.
    
- **해설:** T-34나 현대의 많은 서방권 전차(M1 에이브람스 등)에서 흔히 볼 수 있습니다. 궤도 중앙에 뿔처럼 솟은 핀이 보기륜 사이를 통과하며 궤도를 정렬합니다.
    
- **불러올 경우**
#include <ChDoubleTrackWheel.h>
#include <DoubleTrackWheel.h>

#### **② ChLateralPinRoadWheel (측면 핀용 보기륜)**

- **구조:** 궤도 마디의 양쪽 끝(측면)에 가이드 핀이나 턱이 있는 경우입니다. 보기륜은 통짜 바퀴 형태이며, 양옆의 핀이 바퀴가 궤도 밖으로 나가지 않게 막습니다.
    
- **해설:** 주로 궤도 폭이 좁거나 특수 목적의 차량, 혹은 일부 구형 전차 설계에서 사용됩니다.

- **불러올 경우**
#include <ChSingleTrackWheel.h>
#include <SingleTrackWheel.h>
