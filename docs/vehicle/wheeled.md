# 바퀴 차량

서스펜션, 스티어링, 타이어, 구동계로 구성된 바퀴 차량 시스템.

## 관련 클래스

| 클래스 | 설명 |
|--------|------|
| `ChWheeledVehicle` | 바퀴 차량 기본 클래스 |
| `ChDoubleWishbone` | 더블 위시본 서스펜션 |
| `ChTMeasyTire` | TMeasy 타이어 모델 |
| `ChPacejkaTire` | Pacejka 타이어 모델 |
