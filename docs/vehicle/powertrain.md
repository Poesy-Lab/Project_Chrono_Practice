# 동력계

엔진과 변속기로 구성된 동력 전달 시스템.

## 관련 클래스

| 클래스 | 설명 |
|--------|------|
| `ChEngineSimple` | 단순 엔진 모델 |
| `ChAutomaticTransmission` | 자동 변속기 |
| `ChManualTransmission` | 수동 변속기 |
