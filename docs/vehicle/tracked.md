# 궤도 차량

궤도판, 스프로킷, 아이들러, 롤러로 구성된 궤도 차량.

## 관련 클래스

| 클래스 | 설명 |
|--------|------|
| `ChTrackedVehicle` | 궤도 차량 기본 클래스 |
| `ChTrackAssembly` | 궤도 어셈블리 |
| `ChSprocket` | 스프로킷 |
| `ChIdler` | 아이들러 |
