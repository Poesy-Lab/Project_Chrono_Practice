# 수학 도구

벡터, 쿼터니언(회전), 시간 함수 등 수학 유틸리티.

## 관련 클래스

| 클래스 | 설명 |
|--------|------|
| `ChVector3d` | 3D 벡터 |
| `ChQuaterniond` | 쿼터니언 (회전 표현) |
| `ChFramed` | 위치 + 회전 프레임 |
| `ChFunctionConst` | 상수 함수 |
| `ChFunctionSine` | 사인파 함수 |
