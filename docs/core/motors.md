# 모터 (Motors)

조인트에 모터를 달아 속도/각도/힘을 제어.

## 관련 클래스

| 클래스 | 설명 |
|--------|------|
| `ChLinkMotorRotationSpeed` | 일정 속도 회전 |
| `ChLinkMotorRotationAngle` | 각도 궤적 추종 |
| `ChLinkMotorLinearSpeed` | 직선 속도 제어 |
