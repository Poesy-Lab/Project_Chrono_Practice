# 충돌과 접촉 재질

물체 간 충돌 감지와 접촉 시 마찰/반발 계수 설정.

## 관련 클래스

| 클래스 | 설명 |
|--------|------|
| `ChCollisionShape` | 충돌 형상 정의 |
| `ChContactMaterialNSC` | NSC 접촉 재질 |
| `ChContactMaterialSMC` | SMC 접촉 재질 |
