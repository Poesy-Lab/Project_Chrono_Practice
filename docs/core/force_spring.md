# Chrono에서 힘(Force)과 스프링(Spring) 모델링 이해

## 0. 문서 목적

이 문서는 Project Chrono Phase2에서 다룬 **힘(Force)**, **스프링(Spring)**, **댐퍼(Damper)** 개념을 통합적으로 정리한 문서이다.

Phase2에서 사용한 주요 요소는 다음과 같다.

- TSDA: Translational Spring-Damper Actuator
- RSDA: Rotational Spring-Damper Actuator
- Custom ForceFunctor
- Custom TorqueFunctor
- 이론해와 시뮬레이션 비교
- RMSE 기반 오차 분석

기존에는 TSDA와 RSDA를 각각 따로 이해했지만, 실제로 두 요소는 모두 같은 관점에서 볼 수 있다.

> 물체의 운동 상태를 바꾸는 원인은 힘 또는 토크이고,  
> 스프링과 댐퍼는 변위와 속도에 따라 힘 또는 토크를 만들어내는 물리 모델이다.

---

# 1. 힘(Force)의 기본 개념

## 1.1 힘이란 무엇인가?

힘은 물체의 운동 상태를 변화시키는 원인이다.

뉴턴의 제2법칙에 따르면 병진 운동에서 힘은 다음과 같이 표현된다.

```text
F = m a
```

여기서,

| 기호 | 의미 |
|---|---|
| F | 힘 |
| m | 질량 |
| a | 가속도 |

즉, 힘이 작용하면 물체는 가속도를 갖게 되고, 시간이 지나면서 속도와 위치가 변한다.

Chrono와 같은 동역학 시뮬레이터는 매 시간 스텝마다 물체에 작용하는 힘을 계산하고, 그 힘을 바탕으로 다음 위치와 속도를 계산한다.

---

## 1.2 Chrono에서 힘이 중요한 이유

Chrono에서 물체는 단순히 위치만 이동하는 것이 아니라, 물리 법칙에 따라 움직인다.

즉, 사용자가 직접 물체의 위치를 강제로 바꾸는 것이 아니라 다음과 같은 과정을 거친다.

```text
힘 계산
→ 가속도 계산
→ 속도 업데이트
→ 위치 업데이트
```

Chrono에서 `DoStepDynamics(dt)`를 호출하면 내부적으로 다음 과정이 수행된다.

```text
1. 현재 시간에서 모든 물체의 상태 확인
2. 중력, 접촉력, 스프링 힘, 댐퍼 힘, 외력 계산
3. 제약조건 및 접촉조건 계산
4. 운동방정식 구성
5. 수치 적분을 통해 다음 상태 계산
6. 시간 t를 t + dt로 증가
```

따라서 Chrono에서 가장 중요한 관점은 다음과 같다.

> 어떤 힘을 어떤 물체에 어떤 방향으로 작용시킬 것인가?

---

# 2. 스프링(Spring)의 기본 개념

## 2.1 스프링은 어떤 힘을 만드는가?

스프링은 변위에 비례하는 복원력을 만든다.

가장 기본적인 선형 스프링 모델은 Hooke's law로 표현된다.

```text
F = -k x
```

여기서,

| 기호 | 의미 |
|---|---|
| F | 스프링 힘 |
| k | 스프링 강성 계수 |
| x | 기준 위치로부터의 변위 |

음수 부호는 스프링 힘이 변위를 줄이는 방향으로 작용한다는 뜻이다.

예를 들어,

- 스프링이 늘어나면 다시 줄어들려는 힘이 생긴다.
- 스프링이 압축되면 다시 펴지려는 힘이 생긴다.

즉, 스프링은 항상 기준 상태로 돌아가려는 복원력을 만든다.

---

## 2.2 스프링 강성 k의 의미

스프링 강성 `k`는 스프링이 얼마나 단단한지를 나타낸다.

```text
F = -k x
```

같은 변위 `x`가 발생했을 때,

- `k`가 크면 큰 힘이 발생한다.
- `k`가 작으면 작은 힘이 발생한다.

따라서 `k`가 큰 시스템은 더 빠르고 강하게 원래 상태로 돌아가려 한다.

질량-스프링 시스템의 고유진동수는 다음과 관계된다.

```text
ω_n = sqrt(k / m)
```

즉,

- `k` 증가 → 고유진동수 증가
- `m` 증가 → 고유진동수 감소

---

# 3. 댐퍼(Damper)의 기본 개념

## 3.1 댐퍼는 어떤 힘을 만드는가?

댐퍼는 속도에 비례하는 저항력을 만든다.

가장 기본적인 선형 댐퍼 모델은 다음과 같다.

```text
F = -c v
```

여기서,

| 기호 | 의미 |
|---|---|
| F | 댐퍼 힘 |
| c | 감쇠 계수 |
| v | 상대 속도 |

댐퍼는 운동을 방해하는 방향으로 힘을 만든다.

즉,

- 물체가 빠르게 움직이면 큰 저항력이 생긴다.
- 물체가 천천히 움직이면 작은 저항력이 생긴다.
- 물체가 정지해 있으면 댐퍼 힘은 거의 없다.

---

## 3.2 감쇠 계수 c의 의미

감쇠 계수 `c`는 에너지가 얼마나 빨리 소산되는지를 나타낸다.

`c`가 작으면 진동이 오래 지속된다.

`c`가 크면 진동이 빠르게 줄어든다.

질량-스프링-댐퍼 시스템에서 감쇠비는 다음과 같이 정의된다.

```text
ζ = c / (2 sqrt(m k))
```

감쇠비에 따라 시스템 응답은 다음과 같이 구분된다.

| 감쇠비 | 이름 | 특징 |
|---|---|---|
| ζ < 1 | 부족감쇠 | 진동하면서 줄어듦 |
| ζ = 1 | 임계감쇠 | 진동 없이 가장 빠르게 수렴 |
| ζ > 1 | 과감쇠 | 진동 없이 느리게 수렴 |

---

# 4. 스프링-댐퍼 시스템

## 4.1 기본 모델

스프링과 댐퍼가 함께 있는 시스템은 다음과 같이 표현된다.

```text
F = -k x - c v
```

이 식은 Phase2의 TSDA와 RSDA를 이해하는 핵심이다.

스프링 항은 위치 오차를 줄이고, 댐퍼 항은 속도를 줄인다.

```text
Spring force = -k x
Damping force = -c v
```

즉, 스프링은 위치를 복원하고, 댐퍼는 진동을 줄인다.

---

## 4.2 운동방정식

1자유도 질량-스프링-댐퍼 시스템의 운동방정식은 다음과 같다.

```text
m x'' + c x' + k x = F_ext(t)
```

여기서,

| 항 | 의미 |
|---|---|
| m x'' | 관성항 |
| c x' | 감쇠항 |
| k x | 스프링 복원항 |
| F_ext(t) | 외력 |

외력이 없는 경우는 자유진동이다.

```text
m x'' + c x' + k x = 0
```

외력이 있는 경우는 강제진동이다.

```text
m x'' + c x' + k x = F_0 sin(ωt)
```

# 5. TSDA: Translational Spring-Damper Actuator

## 5.1 TSDA의 의미

TSDA는 두 물체 사이의 병진 방향 스프링-댐퍼 요소이다.

즉, 두 물체 사이의 거리가 변하면 그 변위와 상대 속도에 따라 힘이 발생한다.

```text
F = -k x - c v
```

TSDA에서 변위 `x`는 다음과 같이 정의할 수 있다.

```text
x = l - l0
```

여기서,

| 기호 | 의미 |
|---|---|
| l | 현재 두 연결점 사이의 길이 |
| l0 | 기준 길이 또는 rest length |
| x | 기준 길이로부터의 변위 |

---

## 5.2 TSDA의 물리적 해석

TSDA는 다음 상황을 표현할 수 있다.

- 선형 스프링
- 선형 댐퍼
- 차량 서스펜션
- 로버 현가장치
- 링크 사이의 탄성 연결
- 외력이 있는 강제진동 시스템
- 병진 액추에이터

예를 들어 로버 바퀴와 차체 사이에 TSDA를 넣으면 서스펜션처럼 동작할 수 있다.

---

## 5.3 Chrono 코드 구조

Chrono에서 TSDA는 `ChLinkTSDA`로 생성한다.

```python
spring = chrono.ChLinkTSDA()
spring.Initialize(bodyA, bodyB, False, pointA, pointB)
spring.SetRestLength(rest_length)
spring.SetSpringCoefficient(k)
spring.SetDampingCoefficient(c)
system.AddLink(spring)
```

각 코드의 의미는 다음과 같다.

| 코드                        | 의미               |
| ------------------------- | ---------------- |
| `ChLinkTSDA()`            | TSDA 객체 생성       |
| `Initialize()`            | 연결할 두 물체와 연결점 설정 |
| `SetRestLength()`         | 기준 길이 설정         |
| `SetSpringCoefficient()`  | 스프링 강성 설정        |
| `SetDampingCoefficient()` | 감쇠 계수 설정         |
| `AddLink()`               | Chrono 시스템에 추가   |

# 6. RSDA: Rotational Spring-Damper Actuator

## 6.1 RSDA의 의미

RSDA는 회전 방향 스프링-댐퍼 요소이다.

TSDA가 두 물체 사이의 거리 변화에 따라 힘을 만든다면, RSDA는 두 물체 사이의 상대 회전각과 상대 각속도에 따라 토크를 만든다.

기본 모델은 다음과 같다.

```text
T = -kθ θ - cθ ω
```

여기서,

| 기호 | 의미 |
|---|---|
| T | 토크 |
| kθ | 회전 스프링 강성 |
| θ | 상대 회전각 |
| cθ | 회전 감쇠 계수 |
| ω | 상대 각속도 |

---

## 6.2 TSDA와 RSDA의 차이

TSDA와 RSDA는 구조적으로 매우 비슷하다.

차이는 병진 운동을 다루는지, 회전 운동을 다루는지이다.

| 구분 | TSDA | RSDA |
|---|---|---|
| 운동 종류 | 병진 운동 | 회전 운동 |
| 입력 상태 | 거리, 상대 속도 | 각도, 상대 각속도 |
| 출력 | 힘 | 토크 |
| 기본 식 | F = -k x - c v | T = -kθ θ - cθ ω |
| Chrono 객체 | ChLinkTSDA | ChLinkRSDA |
| 예시 | 서스펜션, 선형 스프링 | 힌지, 조인트, 회전 스프링 |

---

## 6.3 RSDA의 물리적 해석

RSDA는 다음 상황을 표현할 수 있다.

- 회전 조인트의 복원 토크
- 힌지의 탄성
- 로봇 관절의 회전 스프링
- 로버 서스펜션 암의 회전 저항
- 비틀림 스프링
- 회전 감쇠기

예를 들어 문에 달린 힌지를 생각하면, 특정 각도에서 문을 원래 위치로 되돌리려는 토크가 생길 수 있다. 이와 같은 회전 복원 효과를 RSDA로 모델링할 수 있다.

# 7. Custom ForceFunctor와 TorqueFunctor

## 7.1 왜 Custom Functor를 사용하는가?

Chrono의 기본 스프링-댐퍼 모델은 선형 모델이다.

하지만 실제 시스템에서는 다음과 같은 복잡한 힘이 필요할 수 있다.

- 비선형 스프링
- 시간에 따라 변하는 외력
- 제어 입력이 포함된 액추에이터
- 실험 데이터 기반 힘 모델
- 포화 제한이 있는 힘 모델
- 특정 조건에서만 작동하는 힘 모델

이럴 때 사용자가 직접 힘 또는 토크 계산식을 정의할 수 있다.

---

## 7.2 ForceFunctor 예시

TSDA에서 사용자 정의 힘을 만들려면 `chrono.ForceFunctor`를 상속한다.

```python
class CustomSpringForce(chrono.ForceFunctor):
    def __init__(self, k, c, F_amp, F_freq):
        super().__init__()
        self.k = k
        self.c = c
        self.F_amp = F_amp
        self.F_freq = F_freq

    def evaluate(self, time, rest_length, length, vel, link):
        x = length - rest_length

        F_spring = -self.k * x
        F_damper = -self.c * vel
        F_ext = self.F_amp * np.sin(self.F_freq * time)

        return F_spring + F_damper + F_ext
```

이 함수는 매 시간 스텝마다 Chrono 내부에서 호출된다.

---

## 7.3 TorqueFunctor 예시

RSDA에서 사용자 정의 토크를 만들려면 `chrono.TorqueFunctor`를 상속한다.

```python
class CustomRotationalTorque(chrono.TorqueFunctor):
    def __init__(self, k_theta, c_theta):
        super().__init__()
        self.k_theta = k_theta
        self.c_theta = c_theta

    def evaluate(self, time, angle, vel, link):
        T_spring = -self.k_theta * angle
        T_damper = -self.c_theta * vel

        return T_spring + T_damper
```

TSDA에서는 힘을 반환하고, RSDA에서는 토크를 반환한다는 차이가 있다.

# 8. Chrono 내부 작동 흐름

Chrono에서 TSDA 또는 RSDA가 포함된 시스템은 다음 흐름으로 계산된다.

```text
1. 사용자가 물체와 링크를 생성한다.
2. TSDA 또는 RSDA를 시스템에 추가한다.
3. 시뮬레이션 루프에서 DoStepDynamics(dt)를 호출한다.
4. Chrono가 현재 위치, 속도, 각도, 각속도를 계산한다.
5. TSDA/RSDA가 힘 또는 토크를 계산한다.
6. 계산된 힘과 토크가 각 물체에 적용된다.
7. 전체 운동방정식이 풀린다.
8. 다음 시간의 위치와 속도가 업데이트된다.
```

즉, 사용자가 직접 매 시간 힘을 물체에 넣지 않아도, 링크 객체가 내부적으로 힘 또는 토크를 계산한다.

# 9. 이론해와 시뮬레이션 비교

## 9.1 왜 이론해와 비교하는가?

단순한 스프링-댐퍼 시스템은 이론적으로 해를 구할 수 있다.

따라서 Chrono 시뮬레이션 결과와 이론해를 비교하면 다음을 확인할 수 있다.

- 모델이 올바르게 구현되었는가?
- 힘의 부호가 맞는가?
- 기준 길이가 맞게 설정되었는가?
- 초기조건이 일치하는가?
- 시간 간격 `dt`가 충분히 작은가?
- 수치 적분 오차가 허용 가능한가?

---

## 9.2 RMSE 계산

시뮬레이션 결과와 이론해의 차이는 RMSE로 평가할 수 있다.

```text
RMSE = sqrt(mean((simulation - theory)^2))
```

RMSE가 작을수록 이론해와 시뮬레이션 결과가 잘 일치한다.

RMSE가 큰 경우 확인해야 할 것은 다음과 같다.

```text
1. 초기 위치가 이론해와 같은가?
2. 초기 속도가 이론해와 같은가?
3. rest_length 설정이 맞는가?
4. 힘 또는 토크 부호가 반대로 들어가지 않았는가?
5. 외력의 주파수 단위가 rad/s인지 Hz인지 확인했는가?
6. dt가 너무 크지 않은가?
7. 그래프에서 비교하는 변수가 같은 기준으로 정의되었는가?
```

# 10. TSDA와 RSDA를 하나의 관점으로 보기

TSDA와 RSDA는 서로 다른 기능처럼 보이지만, 실제로는 같은 구조를 가진다.

## 10.1 공통 구조

```text
변위 또는 각도 측정
→ 속도 또는 각속도 측정
→ 스프링 항 계산
→ 댐퍼 항 계산
→ 힘 또는 토크 적용
→ 운동 상태 변화
```

## 10.2 대응 관계

| 개념 | 병진 시스템 | 회전 시스템 |
|---|---|---|
| 위치 | x | θ |
| 속도 | v = x' | ω = θ' |
| 질량/관성 | m | I |
| 힘/토크 | F | T |
| 스프링 계수 | k | kθ |
| 감쇠 계수 | c | cθ |
| 운동방정식 | m x'' + c x' + k x = F | I θ'' + cθ θ' + kθ θ = T |

따라서 TSDA를 이해하면 RSDA도 거의 같은 방식으로 이해할 수 있다.

# 12. 로버 최적 설계 프로젝트와의 연결

이번 Phase2에서 힘과 스프링을 학습하는 이유는 단순한 예제 학습이 아니다.

로버 최적 설계에서는 다음과 같은 요소가 모두 힘과 스프링 모델과 연결된다.

- 바퀴와 지면 사이의 접촉력
- 서스펜션의 탄성
- 충격 흡수
- 차체 진동
- 지형에 따른 하중 변화
- 설계 변수에 따른 동역학 응답 변화
- 환경변수에 따른 주행 안정성 변화

예를 들어 로버가 울퉁불퉁한 지형을 지날 때, 서스펜션이 너무 단단하면 충격이 크게 전달된다. 반대로 너무 부드러우면 차체가 크게 흔들릴 수 있다.

따라서 스프링 계수와 감쇠 계수는 로버 설계에서 중요한 최적화 변수로 사용할 수 있다.

# 13. 정리

Chrono에서 힘과 스프링을 이해하는 핵심은 다음과 같다.

```text
힘은 물체의 운동 상태를 바꾸는 원인이다.
스프링은 변위에 비례하는 복원력을 만든다.
댐퍼는 속도에 비례하는 저항력을 만든다.
TSDA는 병진 방향 스프링-댐퍼이다.
RSDA는 회전 방향 스프링-댐퍼이다.
Custom Functor를 사용하면 사용자가 직접 힘과 토크 모델을 정의할 수 있다.
DoStepDynamics(dt)는 이러한 힘과 토크를 포함해 다음 시간의 물리 상태를 계산한다.
```

결국 Phase2에서 TSDA와 RSDA를 학습하는 목적은 다음과 같이 정리할 수 있다.

> Chrono에서 물체가 어떻게 움직이는지를 이해하려면, 먼저 그 물체에 작용하는 힘과 토크가 어떻게 계산되는지 이해해야 한다.  
> TSDA와 RSDA는 그 힘과 토크를 가장 직관적으로 실험할 수 있는 기본 예제이다.
