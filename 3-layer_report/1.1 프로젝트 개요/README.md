# 1.1 프로젝트 개요

이 폴더는 최종 보고서의 `1.1 프로젝트 개요` 절을 담는다. Project Chrono를 선택한 배경, Command-Component-System 학습 구조, 주요 구현 사례와 보고서 전체 구성을 설명한다.

## 섹션 역할

| 항목 | 내용 |
| --- | --- |
| 주제 소개 | Project Chrono가 물리 기반 시뮬레이션 프레임워크로서 어떤 역할을 하는지 설명한다. |
| 선정 배경 | 공식 문서와 모듈 구조가 복잡한 Chrono를 체계적으로 학습해야 하는 이유를 정리한다. |
| 학습 구조 | Command, Component, System 단계가 어떻게 연결되는지 제시한다. |
| 결과물 개요 | 학습 자료, 예제 코드, 구현 사례, 최종 보고서의 위치를 정리한다. |
