# 1.1 프로젝트 개요

이 폴더는 최종 보고서의 `1.1 프로젝트 개요` 절을 관리하기 위한 공간이다.

## 작성 방향

- 캡스톤디자인 프로젝트의 전체 주제와 배경을 설명한다.
- Project Chrono를 사용하는 이유와 시뮬레이션 레이어의 위치를 정리한다.
- 온톨로지, Project Chrono, AI 전처리 레이어가 어떻게 연결되는지 개괄한다.
- 팀이 현재 어떤 학습/구현 단계에 있는지 간단히 설명한다.

## 포함하면 좋은 내용

- 프로젝트 한 줄 요약
- Command-Component-System 3계층 보고서의 목적
- 로버/드론/환경 가상환경 구축이라는 장기 목표
- 팀원별 담당 파트와 보고서 전체 구조 소개
