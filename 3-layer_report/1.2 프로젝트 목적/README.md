# 1.2 프로젝트 목적

이 폴더는 최종 보고서의 `1.2 프로젝트 목적` 절을 관리하기 위한 공간이다.

## 작성 방향

- Project Chrono 학습을 통해 달성하고자 하는 기술적 목표를 설명한다.
- 단순 예제 실행이 아니라, 가상환경을 직접 구성하고 분석 데이터를 출력하는 것이 목적임을 밝힌다.
- Command, Component, System 단계가 각각 왜 필요한지 연결해서 서술한다.

## 포함하면 좋은 내용

- Chrono API를 체계적으로 익히는 학습 목표
- 로버/환경/충돌/주행 시스템 구현 목표
- CSV, 그래프, 렌더 이미지 등 결과 산출물 확보 목표
- 향후 온톨로지와 AI 레이어로 데이터를 전달하기 위한 기반 구축 목표
