# 1.2 프로젝트 목적

이 폴더는 최종 보고서의 `1.2 프로젝트 목적` 절을 담는다. Chrono 학습의 기술적 목표와 Command-Component-System 기반 학습 방법론, 실제 시스템 구현 및 데이터 산출 목표를 정리한다.

## 섹션 역할

| 항목 | 내용 |
| --- | --- |
| 학습 체계 | Chrono 기능을 체계적으로 익히기 위한 3단계 로드맵을 제시한다. |
| 구현 목표 | 로버, 지형, 충돌, 주행 시스템을 직접 구성하는 능력을 목표로 둔다. |
| 데이터 목표 | CSV, 그래프, 렌더 이미지 등 정량/정성 산출물을 확보하는 기준을 설명한다. |
| 확장 기반 | 향후 온톨로지, AI, 최종 프로젝트 주제로 연결될 수 있는 기반을 정리한다. |
