# Manual Chrono Render Captures

이 폴더에는 사용자가 직접 캡처한 Project Chrono VSG/Irrlicht 렌더 이미지를 저장한다.

권장 파일명은 `../../README.md`와 각 `markdown/2.2.x_*.md` 파일에 적어두었다. 같은 파일명으로 PNG를 저장하면 보고서 본문에서 바로 참조하기 쉽다.

권장 캡처 원칙:

| 원칙 | 설명 |
|---|---|
| Component가 화면 중심에 오게 캡처 | Chassis, Wheel, Terrain, Contact point 등 설명 대상이 명확히 보이게 한다. |
| 코드와 이미지가 매칭되게 캡처 | 해당 Component의 코드 예시 바로 아래에 넣을 수 있는 장면을 찍는다. |
| Debug view 적극 사용 | Collision Shape, contact point, force vector는 가능하면 debug 표시를 켠다. |
| 파일명 유지 | 보고서 Markdown에 적힌 파일명을 그대로 쓰면 나중에 삽입이 쉽다. |
