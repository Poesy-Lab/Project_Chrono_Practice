# 2.2.4 Powertrain

## 개요

Powertrain은 driver throttle 입력을 engine torque로 변환하고, transmission을 거쳐 driveline으로 전달되는 driveshaft torque를 생성한다. Chrono::Vehicle에서는 engine과 transmission을 ChPowertrainAssembly로 묶어 vehicle에 연결한다.

## 동력 전달 흐름

**Driver throttle → Engine torque → Transmission torque/speed 변환 → Driveline torque 분배 → Wheel/Tire → Terrain force**

## 구성 요소


| **구성**               | **역할**                                | **대표 함수**                                                |
| -------------------- | ------------------------------------- | -------------------------------------------------------- |
| ChPowertrainAssembly | engine과 transmission을 묶는 aggregate    | GetEngine(), GetTransmission()                           |
| ChEngine             | throttle과 motorshaft speed로 torque 계산 | GetMotorSpeed(), GetOutputMotorshaftTorque()             |
| ChTransmission       | gear ratio와 변속 로직으로 torque/speed 변환   | GetCurrentGear(), ShiftUp(), GetOutputDriveshaftTorque() |

## Engine Models


| **모델**          | **특징**                                 |
| --------------- | -------------------------------------- |
| EngineSimple    | 최대 토크/출력/속도 기반 단순 모델                   |
| EngineSimpleMap | zero/full throttle speed-torque map 보간 |
| EngineShafts    | ChShaft 기반 회전계 관성 및 손실 표현              |

## Transmission Models


| **모델**                         | **특징**                              |
| ------------------------------ | ----------------------------------- |
| AutomaticTransmissionSimpleMap | gear ratio와 shift point map 기반 자동변속 |
| AutomaticTransmissionSimpleCVT | driveshaft speed에 따른 연속 gear ratio  |
| AutomaticTransmissionShafts    | torque converter, shaft inertia 포함  |
| ManualTransmissionShafts       | clutch와 gear box 기반 수동변속            |

## 주요 설정 변수


| **변수**               | **영향**                    |
| -------------------- | ------------------------- |
| engine torque map    | 가속 성능과 등판 성능              |
| zero throttle map    | engine braking 및 감속 특성    |
| gear ratio           | 가속력과 최고속도                 |
| shift point          | 변속 시점과 RPM 운용 범위          |
| torque converter map | 출발 토크 증폭 및 slip           |
| clutch torque limit  | clutch slip과 torque 전달 한계 |

## 정리

초기 차량 주행 실험에는 EngineSimpleMap과 AutomaticTransmissionSimpleMap이 적합하다. 회전계 동역학, torque converter, clutch slip까지 분석해야 하는 경우 shafts 기반 모델을 사용한다.
