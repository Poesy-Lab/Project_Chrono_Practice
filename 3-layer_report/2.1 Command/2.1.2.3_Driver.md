# 2.1.2.3 Driver

## 개요

Driver subsystem은 차량에 steering, throttle, braking 입력을 제공한다. 물리 부품이라기보다는 차량 제어 입력을 생성하는 계층이며, 생성된 입력은 vehicle의 Synchronize 과정에서 steering, powertrain, brake, tire subsystem에 전달된다.

## Driver Inputs


| **입력**     | **범위** | **의미**                                     |
| ---------- | ------ | ------------------------------------------ |
| m_steering | -1 ~ 1 | 좌/우 조향 명령. 실제 조향각은 steering subsystem에서 결정 |
| m_throttle | 0 ~ 1  | engine 또는 motor 출력 요구 비율                   |
| m_braking  | 0 ~ 1  | brake subsystem에 전달되는 제동 입력                |

## Driver 종류


| **Driver**           | **입력 생성 방식**              | **사용 목적**        |
| -------------------- | ------------------------- | ---------------- |
| Interactive Driver   | 키보드/조이스틱 입력               | 수동 조작 및 시각적 테스트  |
| Data Driver          | 시간-입력 데이터 재생              | 반복 가능한 동일 조건 실험  |
| Path Follower Driver | 경로 오차 기반 feedback control | 자율주행/경로 추종       |
| Custom Driver        | 사용자 정의 로직                 | 연구용 제어기 또는 특수 실험 |

## 주요 함수와 설정


| **함수**             | **의미**                             |
| ------------------ | ---------------------------------- |
| GetInputs()        | 현재 steering/throttle/braking 입력 반환 |
| SetSteeringDelta() | interactive driver의 조향 변화율 설정      |
| SetThrottleDelta() | throttle 변화율 설정                    |
| SetBrakingDelta()  | braking 변화율 설정                     |
| Synchronize(time)  | 현재 시간 기준 driver 상태 갱신              |
| Advance(step)      | driver 내부 상태 시간 전진                 |

## Path Follower 개념

Path follower는 현재 차량 위치와 목표 경로 사이의 lateral error와 heading error를 계산하고, PID controller를 통해 steering input을 생성한다. ACC driver는 여기에 속도 제어를 추가하여 목표 속도 유지까지 수행한다.

## 정리

Driver는 차량 모델을 직접 바꾸지 않고 실험 조건을 제어할 수 있는 핵심 요소이다. 반복 실험에는 Data Driver, 경로 추종 실험에는 Path Follower Driver가 적합하다.
