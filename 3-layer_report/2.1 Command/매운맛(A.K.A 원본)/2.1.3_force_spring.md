물체는 운동상태에 놓여지게 되는데, 이를 바꾸는것은 힘 또는 토크이며, 이러한 힘 또는 토크를 바꾸는 요소중 하나는 스프링과 댐퍼가 있다.

Chrono는 물체의 위치가 변화하는것이 아닌 운동을 계산한다. 이는 위치를 시간에 따라 움직이는것이 아닌 힘-가속도-속도-위치를 계산하는 과정을 거침을 의미한다.

Chrono에서 DoStepDynamics(dt)를 호출할 경우 다음과 같은 과정을 내부적으로 수행한다.

1. 현재 시간에서의 물체 상태 확인
2. 중력, 접촉력, 스프링힘등 의 모든 힘 계산
3. 제약조건 및 접촉조건 계산
4. 운동방정식 구성
5. 수치적분을 통해 다음 상태 계산
6. 시간의 dt만큼의 증가
7. 과정 1-6의 반복

스프링의 경우 (Force: F) = -(spring constant: k) x (distance from neutral position: x)으로 정의되는 hooke’s law로 정의되며 댐퍼의 경우 (Force: F) = -(damping constant: c) x (relative velocity: v)의 모델로 정의된다.

따라서 스프링과 댐퍼가 함께있는 시스템은 다음과 같이 정의된다: F= -kx - cv

이러한 스프링 댐퍼 시스템중 병진방향의 스프링 댐퍼(TSDA: Translational Spring Damper Actuator)는 spring = chrono.ChLinkTSDA()로 생성되며 다음과 같은 코드를 가진다

| 코드                                                     | 의미               |
| ------------------------------------------------------ | ---------------- |
| ChLinkTSDA()                                           | TSDA 객체 생성       |
| spring.Initialize(bodyA, bodyB, False, pointA, pointB) | 연결할 두 물체와 연결점 설정 |
| spring.SetRestLength(rest_length)                      | 기준 길이 설정         |
| spring.SetSpringCoefficient(k)                         | 스프링 강성 설정        |
| spring.SetDampingCoefficient(c)                        | 감쇠 계수 설정         |
| system.AddLink(spring)                                 | Chrono 시스템에 추가   |

위와 유사하게 스프링 댐퍼 시스템중 회전 방향의 스프링 댐퍼(RSDA: Rotational Spring Damper Actuator)는 spring = chrono.ChLinkRSDA()로 생성된다
