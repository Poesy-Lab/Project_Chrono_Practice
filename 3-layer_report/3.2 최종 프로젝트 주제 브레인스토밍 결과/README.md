# 3.2 최종 프로젝트 주제 브레인스토밍 결과

이 폴더는 최종 보고서의 `3.2 최종 프로젝트 주제 브레인스토밍 결과` 절을 관리하기 위한 공간이다.

## 작성 방향

- 팀 회의에서 나온 최종 프로젝트 후보 주제를 정리한다.
- 각 주제가 Command-Component-System 구조로 구현 가능한지 간단히 평가한다.
- 실현 가능성, 난이도, 데이터 산출물, 시각화 효과를 기준으로 비교한다.

## 포함하면 좋은 내용

- 후보 주제 목록
- 주제별 필요한 Chrono Command
- 주제별 핵심 Component
- System 단계에서의 조합 예시
- 최종적으로 우선순위가 높은 주제와 선정 이유
