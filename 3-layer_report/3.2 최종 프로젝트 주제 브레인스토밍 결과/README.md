# 3.2 최종 프로젝트 주제 브레인스토밍 결과

이 폴더는 최종 보고서의 `3.2 최종 프로젝트 주제 브레인스토밍 결과` 절을 담는다. 팀 회의에서 도출한 응용 주제를 우선순위에 따라 정리하고, 각 주제가 Command-Component-System 순서로 구현될 수 있는지 검토한다.

## 섹션 역할

| 항목 | 내용 |
| --- | --- |
| 후보 정리 | AI용 물리환경 생성, surrogate model, 게임 물리, 온보드 주행 지원 주제를 정리한다. |
| 구현 조합 | 각 주제를 Command, Component, System 단계로 나누어 구현 순서를 제시한다. |
| 우선순위 | 교수님 연구 방향과 연결성이 높은 주제를 우선 검토한다. |
| 확장 가능성 | 후순위 세부 실험이 최종 주제의 검증 모듈로 쓰일 수 있음을 설명한다. |
