# 3.3 여름방학 및 2학기 향후 계획

이 폴더는 최종 보고서의 `3.3 여름방학 및 2학기 향후 계획` 절을 담는다. 3.2에서 정리한 후보 주제를 바탕으로 여름방학 검토 계획과 2학기 대표 System 구현 계획을 제시한다.

## 섹션 역할

| 항목 | 내용 |
| --- | --- |
| 여름방학 계획 | 후보 주제의 실현 가능성, 데이터 품질, 자동화 가능성을 비교한다. |
| 2학기 계획 | 선택한 주제를 하나의 완성된 Chrono System으로 구현하는 흐름을 제시한다. |
| AI 연동 | Chrono 결과를 AI 평가 데이터 또는 surrogate model 학습 데이터로 연결한다. |
| 최종 산출물 | 입력 조건에 따라 가상환경을 구성하고 결과를 출력하는 프로토타입을 목표로 둔다. |
